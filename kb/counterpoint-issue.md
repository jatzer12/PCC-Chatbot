Counterpoint Issues (Troubleshooting)
keywords: counterpoint, connection, runtime error, Y drive, updates, map drive
Common Cause
Counterpoint issues are typically related to network connectivity, drive mapping, or pending system updates.
What to Check First
Before performing advanced troubleshooting, ensure the computer is connected to the network and has active internet access.
Step-by-Step Troubleshooting
Step 1: Check the network connection
1.	Click the network icon on the computer.
2.	Confirm that the PC is connected to the network.
3.	Open a web browser to verify the PC has internet access.
Step 2: Resolve "Runtime Error"
If you are experiencing a runtime error:
1.	Restart the computer.
2.	Once logged back in, locate the file named "MAP Y drive" on your desktop.
3.	Double-click the file to run it.
4.	Attempt to open Counterpoint again.
Step 3: Resolve "Some devices might not be available"
If you see this specific error message:
1.	Go to Settings.
2.	Navigate to Updates (Windows Update).
3.	Select Check for updates or Process updates.
4.	Wait for all updates to complete.
5.	Restart your computer and try again.
If the Issue Continues
If you have a different error or if the steps above do not resolve the issue:
1.	Restart your computer one more time.
2.	If the error persists, please contact the MIS team for further assistance.
