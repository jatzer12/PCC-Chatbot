# Printer Issues (Cannot Print)

keywords: printer, printing, print, cannot print, printer issue

## Common Cause
Printing issues at PCC are often caused by the computer not being connected to the correct network.

## What to Check First
Before troubleshooting the printer itself, confirm how the computer is connected to the network.

## Step-by-Step Troubleshooting

### Step 1: Check the network connection
Look at how the computer is connected:
- Wi-Fi (wireless), or
- Ethernet cable (wired)

### Step 2: If connected to Wi-Fi
1. Click the Wi-Fi icon on the computer.
2. Check the network name (SSID).
3. Make sure it is connected to **PCC-Wireless**.
4. If it is connected to a different Wi-Fi network:
   - Disconnect from the current network.
   - Connect to **PCC-Wireless**.
   - Try printing again.

### Step 3: If connected to Ethernet (cable)
- If the computer is connected using an Ethernet cable, no Wi-Fi change is needed.
- Proceed to the next step.

## If the Issue Continues
If:
- The computer is connected to **PCC-Wireless**, or
- The computer is connected via Ethernet cable,
